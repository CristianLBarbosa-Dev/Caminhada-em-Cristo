# 🙏 Caminhada em Cristo

Uma landing page em português, feita com carinho, para aproximar as pessoas de Jesus Cristo através de orações, versículos e reflexões.

## ✨ Sobre o projeto

**Caminhada em Cristo** é um convite para conhecer as orações mais belas da Igreja Católica, com explicações que tocam o coração e versículos que renovam a esperança.

Criado por **Cristian**, do TLC de Santa Adélia.

## 📖 Seções

- **Início** — Boas-vindas e apresentação
- **Por que rezar?** — Reflexão sobre o significado da oração
- **Orações** — Coleção de orações para acompanhar o dia a dia
- **Versículos** — Trechos bíblicos que tocam o coração
- **Vivendo em Cristo** — Reflexões sobre a fé no cotidiano
- **Galeria** — Imagens que inspiram
- **Contato** — Formas de entrar em contato

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** puro (sem frameworks), com variáveis CSS para temas de cores e tipografia
- **JavaScript** vanilla para interatividade (modais, galeria, etc.)
- **Google Fonts**: Cormorant Garamond, Lora e Cinzel
- Ícones e ilustrações em **SVG** inline
- Projeto **single-file**, sem dependências externas de build

## 🚀 Como usar

Como é um projeto estático de arquivo único, não há necessidade de instalação ou build.

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/caminhada-em-cristo.git
   ```
2. Abra o arquivo `caminhada-em-cristo.html` diretamente no navegador, ou
3. Sirva com um servidor local simples:
   ```bash
   npx serve .
   ```
